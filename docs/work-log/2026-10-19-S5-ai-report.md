## Key decisions

- Reused path: `screenContext()` in `src/teacher/chat/context.ts` gained a small registry
  (`provideScreenContext`). A mounted Studio lesson registers a source; when a source gives text
  it replaces the lab state (the lab is hidden behind the Studio). The chat's own moderation
  (`checkInput`) and size modes still apply. The switch "Lấy thông tin từ màn hình" decides
  whether anything is sent; no parallel send path.
- Context (`aiContext.ts`): built from the stored session only when a question is sent; sections
  in priority order with their own budgets (lesson/step/rules 500, unverified 400, engine 1500,
  learner 800, last AI text 300; hard cap 3600, below the chat's 4000 compact limit); notes
  quoted ≤ 250 characters; latest engine run first. The expected conclusion is never included.
  Engine numbers use `fmtQty`, the same formatting as the report.
- "Hỏi thầy" opens the chat bubble (`askInBubble`), not the teacher page: only the bubble offers
  screen context. The question names the lesson and step (i18n text, no science, no numbers);
  the learner edits and sends it. Closing the bubble now resets screen context to off, so it is
  off whenever a screen opens the bubble. Hidden in presentation mode (no bubble there).
- Learner notes can now be sent (only with the switch on and a question the learner sends), so
  `studio.notes.private` no longer says "không gửi đi đâu"; it says when they are sent.
- Unverified data: engine evidence gets optional `review_status` (old stored sessions still
  load). Chemistry library mixes copy the reaction record's status; biology stage and answer-
  sheet records copy the 3D model card's status (`card3d(...).reviewStatus`); physics engine runs
  carry none (numbers computed by code). `unverifiedItems` + `unverifiedLabel` give one list and
  one wording to the report and the AI context. Existing per-record "review" facts are unchanged.
- Report: view (existing preview), save (existing `saveFile`), copy (new, Clipboard API; on
  failure a toast tells the learner to select and press Ctrl+C). No export helper for the
  clipboard existed in the app.
- Resume: sessions were already persisted (`stemsim.studio`); the lesson shown per subject
  (`picked`) is now persisted too and validated on load (a bad value is dropped, sessions kept).
- No new dependency. No new scientific text, so no DATA_REVIEW entry.
